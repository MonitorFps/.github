## 🧠 Overview

MonitorFPS is a lightweight desktop utility designed to provide real-time information about gaming performance. It helps users keep track of frame rate and other useful performance indicators while running games.

The application provides a convenient way to monitor system behavior during gameplay without constantly switching between different applications.

---

## 🚀 Key Features

| Feature | Description |
|---|---|
| 📊 FPS Counter | Display real-time frames-per-second information while gaming. |
| 🖥️ Performance Monitoring | Keep an eye on important system performance indicators. |
| 🎮 In-Game Overlay | View monitoring information while a game is running. |
| ⚡ Lightweight Design | Designed to remain convenient during gaming sessions. |
| 📈 Real-Time Data | Monitor performance information as it changes. |
| 🔧 Simple Interface | Easy-to-understand controls and monitoring options. |

---

## 💻 System Requirements

- **Operating System:** Windows 10 / Windows 11
- **Processor:** Modern dual-core CPU or better
- **RAM:** 4 GB minimum
- **Storage:** At least 500 MB of available space
- **Graphics:** DirectX 11 compatible GPU
- **Display:** 1280×720 resolution or higher

---

## Additional Information for Windows Users

MonitorFPS is designed for Windows users who want a convenient way to observe gaming performance in real time.

Performance information can vary depending on the game, hardware configuration, graphics settings, drivers, and background applications. For the most consistent results, keep your graphics drivers and Windows installation up to date.
